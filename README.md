# tadhakkar-site

Pages publiques de l'application iPhone **Tadhakkar** (dhikr, adhkār, Noms
d'Allah, Coran, Qibla), servies par GitHub Pages.

| Fichier | Rôle | Exigence Apple |
|---|---|---|
| `index.html` | Aide, questions fréquentes, contact | **Support URL** de la fiche App Store |
| `confidentialite.html` | Politique de confidentialité (FR + EN) | **Privacy Policy URL**, obligatoire |

Ce dépôt est public **uniquement** parce qu'App Store Connect exige deux URL
publiquement accessibles. Il ne contient aucun code : le code source de
l'application reste dans son dépôt privé.

## Tenir les pages à jour

`confidentialite.html` est la copie de `docs/confidentialite.html` du dépôt de
l'application. Les deux doivent rester identiques, et l'écran
« Confidentialité » de l'application doit dire la même chose qu'elles : ce sont
trois énoncés du même engagement, et l'un ne peut pas contredire les autres.
Après toute modification, corriger les trois et mettre à jour la date.
